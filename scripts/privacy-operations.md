## 문의 접수

일반 문의는 수집·이용과 국외 이전 각각의 동의 문구가 있는지 확인한다. 확인란 자체를 서버에 저장하지 않으며 실제 발송된 메일이 기록이다. 이용자가 문구를 삭제했거나 사이트 안내를 거치지 않고 보낸 경우, 동의를 받았다고 간주하거나 임의로 동의 문구를 추가하지 않는다. 필요한 적법한 근거와 안내를 확인한 뒤 처리한다. 법정 권리 행사나 법정 의무 기록에 신규 일반 문의 동의를 강제하지 않는다.

첨부파일은 필요한 것만 취급한다. 문의 해결에 필요하지 않은 민감정보·식별번호를 요청하지 않는다. 어린이의 동의 기반 문의는 법정대리인 확인 절차를 진행한다. 메일 보안 기능이나 위험 첨부파일 경고를 해제하지 않는다.

## 완료 및 삭제

문의가 해결되면 완료일을 메일함 안에서 표시한다(예: `완료/2026-10-04` 라벨). 완료일이 확인되지 않은 문의에 수신일을 완료일로 대신 사용하지 않는다. 추가 문의로 재개되면 마지막 처리 완료일을 확인한다.

달력상 6개월을 적용하며 180일과 같다고 간주하지 않는다. 더 이상 필요하지 않은 정보는 지체 없이 삭제한다. 양현석의 월별 점검은 미삭제 누락을 확인하는 보완 절차이며, 황재동이 결과를 확인한다. 삭제 점검 기록에는 문의 본문이나 불필요한 개인정보 사본을 남기지 않는다.

법정 보관 대상과 진행 중인 분쟁을 일반 문의에서 구분한다. 해당 기록의 적용 법령·종료 시점을 확인한다. 자동 보관 제외 라벨을 붙였다고 영구 보관할 수 있다고 생각하지 않는다.

메일·첨부파일과 휴지통을 삭제한다. Google의 복구·백업 기간은 TeamHJD의 이용 기간과 구분한다. 별도 PC·Drive 사본을 만들지 않는다. 실수로 만들어진 사본이 있으면 같은 삭제 기준을 적용한다.

새 분석 도구, 폼, 외부 임베드, 게임 개인정보 처리, 채용·결제 업무를 추가하면 먼저 항목·근거·위탁·국외 이전·보관·권리 절차를 재검토한다. Google의 재위탁 변경 통지와 국외 이전 동의에 영향을 주는 변경을 검토한다. 일반 문의 동의/국외 이전 문구가 변경되면 단순 페이지 갱신으로 기존 동의를 갈음하지 않는다.
