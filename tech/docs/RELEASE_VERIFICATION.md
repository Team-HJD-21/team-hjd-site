기준일은 2026년 11월 3일입니다. 운영 주소는 https://tech.teamhjd.com/ 입니다.

## 실제 확인한 내용

- 운영 HTTPS 200, 별도 글 목록·태그·구독 페이지, 날짜/제목 기사 주소, 기존 주소의 HTTP 301, RSS·publication.json의 날짜 경로를 확인했습니다. Markdown·ZIP도 실제 HTTP 200입니다.
- 공통 favicon 9개는 회사 manifest의 SHA256과 운영 파일이 모두 일치했으며 SVG·PNG·ICO Content-Type도 확인했습니다.
- 첫 글의 PNG 3개는 로컬과 운영 SHA256이 일치했습니다. SVG 3개는 내용이 같고 Windows 줄바꿈만 달랐으며, 현재는 자산별 LF 규칙으로 고정했습니다. 그림·CSS·JS URL에는 내용 해시를 붙이고 HTML 재검증을 설정했습니다.
- 사용자가 운영 사이트에서 인증 메일 수신과 확인 버튼을 통한 구독 완료를 직접 확인했습니다. 수신 주소는 문서와 공개 Git에 기록하지 않습니다.
- 새 인증 대기 흐름은 실제 브라우저와 모의 메일 서버에서 입력 잠금 → 확인 링크 → 확인 버튼 → 원래 신청 탭 ‘구독 완료’ 갱신까지 확인했습니다. 개인정보를 외부로 보내지 않는 로컬 시험입니다.
- 관리 폼 → 관리 메일 → 서명된 해지 링크 → 해지 버튼 → 이메일 삭제 안내도 같은 모의 서버와 D1 호환 SQLite 검사에서 확인했습니다.
- 로고·다크 카드·핵심 버튼·명확한 해지 버튼을 가진 메일 HTML을 실제 브라우저로 렌더링했습니다. Gmail·Outlook·Apple Mail의 모든 버전에서 같은 픽셀로 보인다는 의미는 아닙니다.
- 확대 그림은 모바일 320px 및 기본 창에서 팝업과 그림 영역의 client/scroll 크기가 같음을 확인했습니다. 그림은 object-fit:contain으로 전체가 보입니다. 원본은 별도 링크로 엽니다.

## 운영 경계

브라우저 이탈 경고는 beforeunload를 대기 중에만 연결하고 완료 시 해제합니다. 경고 문구와 표시 여부는 브라우저가 결정합니다. 내장 브라우저 자동화에서 네이티브 이탈 경고 팝업 자체는 확인하지 못했으며, 코드 연결과 원래 탭 완료 갱신을 검증했습니다. [브라우저 공식 참고](https://developer.mozilla.org/en-US/docs/Web/API/Window/beforeunload_event)를 따릅니다.

ChatGPT의 기존 클라우드 예약을 이 작업에서 수정한 것은 아닙니다. 인계받은 GPT가 실제 기존 예약을 확인·갱신하고 Run now로 시험해야 합니다. 11월 3일 정기 메일 3건은 실제 운영 발송 원장에서 API 수락을 확인했습니다. 이 기록만으로 실제 받은편지함 도착이나 앞으로의 예약 실행을 완료로 표시하지 않습니다.

최종 커밋·CI·인증 연결 검사 결과는 전달 폴더의 배포 실행 기록을 확인해 주세요. 원고 검사와 운영 URL 검증, 메일 API 수락과 실제 받은편지함 도착은 구분합니다.
