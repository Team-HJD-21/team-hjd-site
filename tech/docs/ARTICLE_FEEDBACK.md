# 글별 반응 수집

각 정식 글 맨 아래에서 ‘유용해요’, ‘더 궁금해요’, ‘어려워요’, ‘좀 쉬워요’ 중 한 가지를 선택합니다. 선택은 바꾸거나 취소할 수 있습니다. 같은 브라우저·같은 호의 반응은 D1 기본키로 한 건만 저장하며, 재시도와 동시 요청도 총 참여 수를 늘리지 않습니다. 선택을 바꾸면 이전 분류에서 빠지고 새 분류로 옮겨집니다.

처음 반응을 누를 때만 서명된 임의 쿠키를 만듭니다. Secure·HttpOnly·SameSite=Strict와 __Host 접두사를 사용하며 최대 365일 유효합니다. 쿠키를 차단한 환경에서는 집계를 시작하지 않습니다. 단순 열람은 쿠키나 IP 제한값을 만들지 않습니다. 이메일·구독자 ID와 연결하지 않습니다.

IP는 Cloudflare가 전달한 CF-Connecting-IP만 사용하며 X-Forwarded-For로 대체하지 않습니다. 원본 IP 대신 기존 비밀키로 HMAC한 일시 제한값을 저장합니다. 같은 IP에서 변경 요청은 시간당 60회, 같은 글의 신규 브라우저 참여는 한국 날짜당 5개까지 허용합니다. 같은 와이파이의 다른 독자도 참여할 수 있게 한 절충입니다. 기존 반응 변경·취소는 신규 참여 한도를 쓰지 않습니다. 신규 반응과 한도 증가는 하나의 D1 batch transaction으로 처리합니다.

반응 행은 마지막 변경부터 365일까지 조회하며, 만료 데이터와 시간·날짜가 끝난 요청 제한값은 다음 변경 요청에서 정리합니다. 브라우저 식별값은 서버에 HMAC으로만 저장하고, 원본 IP 주소·쿠키 원문·기기 지문은 저장하지 않습니다. 쿠키·기기·네트워크를 모두 바꾸는 사용자를 로그인 없이 완벽히 구분할 수는 없습니다.

공개 API는 GET /api/feedback?issueId=호-ID, POST /api/feedback, DELETE /api/feedback입니다. POST·DELETE는 동일 Origin의 JSON만 허용합니다. 배포된 publication.json에 있는 호만 받으며 임의 글·초안의 반응은 만들지 않습니다. GET은 현재 브라우저의 선택만 반환합니다. 공개 합계나 개별 식별값 조회 API는 없습니다. 응답은 no-store이며, 오류·로그에 원본 IP나 쿠키를 출력하지 않습니다. Resend를 호출하거나 메일 한도를 사용하지 않습니다.

운영자는 기존 바탕화면의 ‘겜붕이의 노트 관리’를 열고 ‘글 반응’ 탭에서 글별 네 분류·합계·최근 변경 시각을 확인합니다. 합계는 최근 365일 이내의 현재 선택이며 일별 누적 클릭 수가 아닙니다. 발송 내역 조회일과 관계없이 전체 글을 보여줍니다. 집계만 기존 암호화 보고서에 포함하고, voter_hash·IP 제한값·생성 키는 보고서에 넣지 않습니다. GPT가 매일 원고를 만들 때 이 비공개 도구를 자동 실행하지 않습니다. 운영자가 공유한 집계가 있다면 다음 설명의 난이도와 주제를 정하는 참고 자료로 사용해 주세요.

새 호에서는 버튼을 본문에 직접 복사하지 않습니다. 공통 articleContent 템플릿이 호 ID를 연결합니다. 호 ID·날짜·원고·그림·발송 receipt를 바꿀 필요가 없습니다. 기존 DB 바인딩과 TOKEN_SECRET을 사용하며 별도 키·유료 서비스·권한 확대는 없습니다. 새 테이블 두 개와 인덱스만 추가하며 기존 구독·발송 테이블은 보존합니다.

검증은 읽기 시 무추적, 쿠키 요구, 재클릭·선택 변경·취소, 서로 다른 글, 공유 IP, 한국 자정 초기화, 동시 신규 참여, 시간 제한, CSRF·잘못된 본문·초안 차단, 트랜잭션 실패 복구, 보관 기간과 비공개 집계를 포함합니다. 실제 운영 DB에 가짜 반응을 넣지 않고 격리된 SQLite와 브라우저 QA로 검사합니다.
