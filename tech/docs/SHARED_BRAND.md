# TeamHJD 공통 디자인

회사 사이트의 최신 소스가 기준이다. 별도 채팅 `teamhjd.com`과 사용자 요청에 따라 관련 사이트 연결 및 푸터 기준을 협의한다.

`scripts/company-brand.mjs`는 저장소 루트 `styles.css`, `index.html`의 공통 푸터, `assets/teamhjd-wordmark.png`를 읽는다. 뉴스레터 빌드에는 `assets/teamhjd.css`와 동일한 푸터가 포함된다. 상대 링크는 회사 사이트의 절대 URL로 바꾸고, 관련 사이트 메뉴에는 TeamHJD 홈을 추가한다. 회사 쪽 메뉴가 바뀌면 다음 빌드에 반영된다. 법적 표기·정책·사업자정보를 별도로 복제해 관리하지 않는다.

배경은 회사 CSS의 `--bg`, 표면은 `--surface`, 구분선은 `--line`, 보조 글자는 `--muted`, 강조는 `--accent`를 사용한다. 2026-11-03 기준 실제 어두운 테마의 배경은 #080f17, 표면 #13202c, 푸터 #060c13, 강조 #d9eea6이다. Pretendard / Noto Sans KR / system-ui 글꼴도 맞춘다.

뉴스레터 본문의 읽기 폭, 코드·표의 내부 스크롤, 수식·그림·다운로드 등 읽기 기능은 전용 CSS로 유지한다. 밝은 테마에서도 공통 푸터는 회사의 어두운 푸터 색과 대비를 유지한다.

브랜드 로켓은 원본 PNG를 그대로 재사용한다. 글자·파비콘 구성은 BRAND_SOURCES.md를 따른다. 매일 원고 생성 작업은 브랜드·템플릿·공통 회사 소스를 변경하지 않는다.
