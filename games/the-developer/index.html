게임이 궁금하다면

출시를 목표로 개발 중이며, 일정과 세부 내용은 변경될 수 있습니다.

어떤 게임인가요?

제한된 전력을 터렛에 나누고 직접 전투에 참여하며 외계 생명체를 막는 전략 디펜스 게임입니다.

어떤 플랫폼을 지원하나요?

Windows와 macOS를 지원할 예정입니다.

혼자서도, 다른 사람과 함께도 플레이할 수 있나요?

싱글플레이와 멀티플레이를 모두 지원합니다.

게임에서 어떤 언어를 사용할 수 있나요?

한국어와 영어를 지원하며, 중국어 지원도 추후 추가할 예정입니다. 웹사이트 언어와 게임 지원 언어는 구분됩니다.

언제 출시하나요?

2027년 2월 출시를 목표로 개발 중입니다. 일정이 변경되면 공식 채널을 통해 안내합니다.
